## Commercial policy and preserved terms

Independent investors see the guide's Helios, Orbis and Ledger shelf. Referred investors see all published deals: nine non-draft deals in the current seed, including the guide's original five and four later additions. Draft Cobalt remains unpublished. New deals default to referred access unless added to `INDEPENDENT_FUND_IDS` in `src/lib/investor-access.ts`. Closed deals may remain visible but cannot accept a new application. Existing holdings and applications remain readable when the investor changes commercial profile.

The effective published fee, including any investor-specific LUCA override, is the base. Independent applications add **one percentage point**; referred applications use the effective base and record partner priority. For example, a custom 2.5% fee becomes 3.5% for an independent investor. Listing, deal detail, checkout and the saved application use the same calculation. Priority is a classification for operator decisions; no automatic allocation ranking engine is claimed.

New applications freeze their effective terms and commercial classification. Later deal edits, custom-pricing changes or demo segment switches do not reprice an existing application. Legacy applications retain their existing recorded subscription fee and signed snapshot; no historical commercial classification is invented.

## Simulation boundaries

MSW and browser-local storage remain the transport and persistence model. Verification files, signatures, payment declarations, receipt matching, registry issuance and settlement are demo records. There is no live bank, administrator, email provider, scheduled-send worker or automatic monthly valuation service. Manual dated valuations and real demo inbox-open events are recorded; external delivery and live settlement are not claimed. Existing per-user and institution scope checks remain enforced in the model/API tests.
